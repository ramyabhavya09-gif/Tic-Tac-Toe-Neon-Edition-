
# 🎮 Ultimate Tic-Tac-Toe — Neon Edition

A stylish neon Tic-Tac-Toe browser game where you can challenge a smart computer opponent or play against a friend.

## Features

- Player vs Computer mode
- Smart, unbeatable AI using the Minimax algorithm
- Two-player mode
- Automatic win and draw detection
- Highlighted winning combinations
- Score tracking for both players and draws
- New Round and Reset Scores controls
- Responsive mobile-friendly design
- Neon colors, glowing effects, and smooth animations
- No external libraries, APIs, or installations

## Technologies

- HTML5
- CSS3
- JavaScript
- Minimax algorithm

## Project Files

- `index.html` — Game structure
- `style.css` — Neon interface and responsive layout
- `script.js` — Game logic, scoring, and AI
- `README.md` — Project documentation

## How to Play

### Player vs Computer
1. Select Player vs Computer.
2. You play as X.
3. The computer plays as O.
4. Get three matching symbols in a row, column, or diagonal to win.

### Two Players
1. Select Two Players.
2. Player X takes the first turn.
3. Players alternate between X and O.
4. The first player to make three in a row wins.

## Run Locally

Open `index.html` in any modern web browser.

## Deploy on GitHub Pages

1. Upload all four project files to the root of your GitHub repository.
2. Open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the `main` branch and `/ (root)` folder.
5. Click Save.
6. Open the published GitHub Pages URL after deployment finishes.

## About the AI

The computer uses Minimax to examine possible future moves and select an optimal move. With perfect play, the computer cannot lose in standard 3×3 Tic-Tac-Toe.

## Learning Objectives

This project demonstrates event handling, arrays, game-state management, conditional logic, DOM manipulation, responsive styling, and adversarial search.
